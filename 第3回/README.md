# 第3回 CSSとボックスモデル

第2回の図鑑を、画像・動物名・リンクを囲んだカードと、中央に配置した白いページへ調整した完成版。

## 表示方法

`index.html` をブラウザで開く。

## ファイル

~~~text
第3回/
├── index.html
├── style.css
└── images/
    └── red-panda.png
~~~

## 確認

- 動物名・画像・リンクがカードの枠に収まる
- 枠の内側のpaddingは16px、borderは2px、外側の上下のmarginは24px
- 白いページは中央に配置され、最大幅は680px
- 画面を狭めると画像が縮み、横にはみ出さない

第2回の画像を使用。自分の作品では動物名・画像パス・リンク先を自分の題材に合わせる。
