# 第4回 Flexbox・Grid・レスポンシブ対応

第3回の図鑑に、3枚のカードとページ内ナビを追加した終了時点のコード。

## 表示

1. フォルダの構成を保ったまま、`index.html` をブラウザで開く。
2. ページ上部のナビから、ペンギンなどのカードへ移動。
3. 開発者ツールのレスポンシブ表示で、表示幅を320・599・600・899・900pxに変更。

| 表示領域の幅 | カード |
| --- | --- |
| 600px未満 | 1列 |
| 600px以上、900px未満 | 2列 |
| 900px以上 | 3列 |

ナビはFlexbox、カードはGridで配置。Node.jsやパッケージのインストールは不要。
