# 第11回 ReactのJSX・コンポーネント

ペンギンの図鑑を3つのコンポーネントで組み立て。src/AnimalCard.jsx の name を一時的に変更し、見出しへの反映を確認。

## 起動

1. Node.js 24系を使用。
2. このフォルダで `pnpm install`、`pnpm dev`。npmの場合は `npm install`、`npm run dev`。
3. ブラウザーで `http://127.0.0.1:4171/` を開く。停止は Ctrl+C。

リポジトリをまとめて取得した場合は、ルートで `pnpm install`、`pnpm --filter zukan-11 dev`。
