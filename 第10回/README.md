# 第10回 絞り込み・お気に入り・localStorage

名前検索に分類とお気に入りを追加。登録した動物のIDは同じブラウザーの同じURLで再読み込み後も復元。

1. Node.js 24系を使用し、このフォルダで `pnpm install`、`pnpm dev`。npmの場合は `npm install`、`npm run dev`。
2. `http://127.0.0.1:4170/` を開く。
3. 分類を「鳥類」に変更。ペンギンをお気に入りに登録。
4. 分類を「すべて」に戻し、「お気に入りのみ」でペンギン1件を確認。
5. 再読み込みし、「お気に入りのみ」を選択。登録が残っていることを確認。

リポジトリ全体をダウンロードした場合は、ルートで `pnpm install` を1回実行し、`pnpm --filter zukan-10 dev` で起動。開発サーバーの停止は Ctrl+C。
