# 第5回 静的なWeb図鑑の完成

第4回の図鑑を仕上げた、HTML・CSS編の完成見本。

## ファイル

- `index.html` ／ 図鑑の本体
- `style.css` ／ 図鑑と練習ページの見た目
- `images/` ／ 第4回から引き継いだ画像
- `form-practice.html` ／ 入力と送信を観察する発展練習

## 表示と確認

1. ファイルの構成を保ったまま、`index.html` をChromeまたはEdgeで開く。
2. 画面幅320px・600px・900pxで、カードの列数と画像を確認。
3. TabとEnterでカードへ移動し、末尾のリンクで先頭へ戻る。
4. 自分の題材では、画像ファイル・`src`・`alt` と、ナビの `href`・カードの `id` を照合。

フォーム練習は `form-practice.html` を直接開く。空欄の送信と、動物名を入力したときのアドレスを比較。入力例は「ペンギン」。

Node.jsやパッケージのインストールは不要。
